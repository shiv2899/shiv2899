## 🛠️ How I Like to Build

- **Start with the question and a baseline.** Complexity only helps when it adds useful information.
- **Evaluate honestly.** Keep test data truly held out, and report limitations alongside results.
- **Make results understandable.** Clear visualizations and explanations matter as much as model metrics.
- **Learn by building.** Work with real datasets and share the process, not just the headline number.
