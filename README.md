## 🚀 Featured Projects

### 🌍 [EarthPulse](https://github.com/shiv2899/earthpulse)
An interactive climate dashboard using NASA POWER data to explore temperature and rainfall trends for Kanpur, India, and forecast temperature through 2030.

- Uses Python, Pandas, Streamlit, Matplotlib, and scikit-learn.
- Presents historical climate trends and a linear-regression temperature forecast.

### 🛰️ [Spacecraft Anomaly Detection](https://github.com/shiv2899/spacecraft-anomaly-detection)
An LSTM-based detector for NASA JPL SMAP satellite and Curiosity rover telemetry, using dynamic thresholds to identify anomalous behavior.

- Reported precision of **0.689**, compared with **0.068** for the repository's 3-sigma Z-score baseline.
- Evaluation covers 66 channels; 17 short channels were skipped, so results are not directly comparable to the cited paper's full-dataset results.

### 🪐 [Exoplanet Finder](https://github.com/shiv2899/exoplanet-finder)
A two-view CNN experiment for classifying Kepler candidates, evaluated on unseen stars and compared against a gradient-boosting baseline.

- On the test split of 1,426 signals from 1,223 unseen stars, the baseline reached **0.842 AUC** and the CNN **0.683 AUC**.
- The project documents why the baseline performed better: the CNN's synthetic views did not add information beyond the input features.
