### 🛰️ Spacecraft Anomaly Detection
**Can a model spot when telemetry stops looking normal?**

An LSTM detector for NASA JPL SMAP satellite and Curiosity rover telemetry, paired with dynamic thresholding.

Reported **0.689 precision** versus **0.068** for the project’s 3-sigma Z-score baseline. Evaluation covered 66 channels; 17 short channels were skipped.

**Python · LSTM · Time series · NASA data**

### 🪐 Exoplanet Finder
**Does a deep-learning model always beat a simpler baseline?**

A two-view CNN experiment classifying Kepler candidates, evaluated on signals from stars held out from training.

On 1,426 test signals from 1,223 unseen stars, the gradient-boosting baseline reached **0.842 AUC**; the CNN reached **0.683 AUC**. The project investigates why the simpler model won.

**Python · CNN · PyTorch · Kepler**

[Explore the experiment →](https://github.com/shiv2899/exoplanet-finder)

## 🧭 How I like to build

- **Start with the question and a baseline.** Complexity only helps when it adds useful information.
- **Evaluate honestly.** Keep held-out data truly held out, and report limitations alongside results.
- **Make results understandable.** Clear visualizations and explanations matter as much as model metrics.
- **Learn by building.** Work with real datasets and share the process, not just the headline number.
